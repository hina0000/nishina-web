Class Guide

クラス案内

初等科

対象：3歳～6歳

リズム感が身につくように音楽に合わせて体を動かします。

☆ご挨拶ができるように
☆先生のお話が聞けるように
☆お友達とのコミュニケーションが取れるように
クラスを進めています。

月末には見学日を設けてお子様の成長を感じていただくことができます♪

中等科B

対象：小学1年生～小学3年生 または バレエ初心者

バレエの基礎動作と用語を学びながら、バレエ特有の優雅な動きを習得します。

身体の動かし方が理解できるように、にしなバレエオリジナルのメソットを用いています。

中等科A

対象：小学4年生～小学6年生 または バレエ経験者

トゥシューズを用いて本格的なバレエの練習に入ります。
基礎動作だけでなく、コンビネーションな動きも習得します。

レッスン回数は1回～5回まで受講ができ、コンクールクラスにも所属できます。

高等科

対象：中学生以上

発表会で主要なキャストを踊れるように、さまざまなバレエの動きを習得します。

海外留学や外部の公演に出演する機会があります。

大人のバレエクラス

対象：誰でも大歓迎　未経験者・初心者の方も大歓迎です♪

初心者の方から経験者の方まで満足していただけるプログラムを提供しています。

同世代ならではの悩みを共有し、時には地元ネタで会話が盛り上がりながらクラスを進めています。
『身体が軽くなるだけではなく、心までリフレッシュできる』と口コミで輪が広がっています。

※オープンクラスですので、事前予約は不要です。ご都合に合わせて通っていただけます。

レッスンをお休み、遅刻・早退するなどの場合は、必ずスタジオLINEまたは090-6502-3767までの連絡をお願い致します。

保護者の方の見学は、生徒の集中力の妨げとなりますので、初等科は月末の1回、小学生クラスはご遠慮頂いております。

Information

その他のご案内

振替制度について

振替レッスンはレッスン日に欠席をした場合に同じ名称のクラスへ振替ができます。期限は年末の最終レッスン日まで。振替レッスンをご希望の方は担当教師にお知らせ下さい

クラスについて

入会時に希望をするクラスに所属で出来ない場合、空き次第連絡を致します。

クラスやレッスン回数の変更は前の月の月末までにお申し出下さい。又月単位での曜日変更は承れません。所属クラスをお決めになる際は長期で通える曜日をお選び下さい。

服装および髪型について

バレエに適したレオタードを着用してください。（色やデザインは自由です。）初等科クラスはスカート付きのレオタード可、小学生クラスからはスカートなしのレオタードにしていただきます。

髪の毛はシニヨンにまとめてください。

髪の毛が短い方はオデコ・首周りが見えるようにまとめてください。

発表会について

生徒の成長を目的とし、発表会は全員参加をお願いしております。また発表会時は保護者の方にお手伝いなどのご協力をお願い致します。

練習期間は、通常のレッスン以外にも、リハーサルを行います。ご理解とできる限りのご参加をお願い致します。

1年半に1回、発表会を開催予定です。
